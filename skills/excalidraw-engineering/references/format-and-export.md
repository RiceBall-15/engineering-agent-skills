# 格式、样式与导出

本技能不捆绑 Excalidraw 应用或浏览器运行时。生成和导出前先查看宿主可用工具；不把示例命令中的占位路径原样执行。

新环境的具体安装命令与中文示例验收见 [安装与首次验收](setup.md)。推荐先复用已有能力；需要新配置本地 PNG 导出时，优先按指南使用官方 CLI，避免无必要地维护另一套渲染脚本。

## 生成路径

优先级：可用且符合任务范围的 Excalidraw 集成/编辑器 → 已配置的本地 Excalidraw 生成与渲染工具 → 直接构建源 JSON，再用实际编辑器验证。

使用集成前读取其工具说明和支持的格式。直接生成时可复用当前环境已有、已核对的元素模板；不能复制开发者个人机器的绝对路径作为团队依赖。

如果存在 `excalidraw-diagram` 技能，可按需要读取其元素模板与渲染器说明，不必为绘制一张简单图加载全部设计流程。没有该技能也可以通过可用 Excalidraw 编辑器完成。本技能的工程范围、输出目录及用户指定样式仍需遵守。

## 源文件要求

常见 `.excalidraw` 文档包含 `type: "excalidraw"`、文件 `version`、`elements`、`appState` 和 `files` 等字段。具体元素及绑定结构以实际工具支持的格式为准；不能把文件版本号当成应用版本号。

- 元素使用稳定且唯一的 ID，例如 `api_service`、`decision_allowed`、`edge_api_storage`。局部修订保留旧 ID，新增元素使用不冲突的 ID。
- 字符串使用合法 JSON 转义，文字字段放可读文本。源码或用户数据作为文本处理，不能拼接为可执行脚本或 HTML。
- 坐标、尺寸、折线点为有效有限数值。箭头/线的点通常是相对自身位置的坐标；以使用的模板或 API 为准，避免混入绝对坐标导致偏移。
- 节点内的文字尽量使用正式文字绑定；文字的 `containerId` 与容器的 `boundElements` 应互相对应。自由标题/注释无需伪造绑定。
- 箭头两端使用实际支持的绑定结构，检查目标存在并补齐相应反向引用。未绑定的箭头看起来连接正常，也可能在拖动节点后脱落。
- 对已有文件，保留不认识但合法的字段，避免旧模板破坏新版功能；不能随意删掉关联、frame 或图片信息。
- 使用图片时保证 `fileId` 对应的数据存在；使用框架支持的内嵌图片资源使文件尽量自包含。不得引用作者临时目录或依赖外部登录态。
- 保留合理画布背景，裁切范围包含标题、图例、箭头和注释；导出时排除删除态元素，避免把已删除草稿误导出。

## 团队排版约定

以下数值是本技能的默认画布单位，不是 C4/UML/BPMN 官方要求。先按默认布局，按实际预览调整；任何调整都必须保证正常阅读尺寸下可辨认。

| 项目 | 默认要求 |
| --- | --- |
| 对齐 | 采用 8 单位网格，同层节点对齐中心或边缘；语义相同的节点保持一致尺寸策略 |
| 节点留白 | 文字与边框至少 16；边界框距内部节点至少 24，顶部另留标题空间 |
| 节点与分区间距 | 相邻节点通常至少 40；有连线标签的通道通常至少 64，放不下则扩大通道 |
| 字号 | 图题 28–32，节点 18–22，关系标签 16–18，辅助注释 14–16；不能缩小关键标签塞内容 |
| 文字层级 | 节点名称、类型/技术、职责分行；职责尽量 1–2 行，超长细节移到 README |
| 连线 | 架构/流程优先正交或简洁直线，时序消息水平或向下；折点最少且不穿无关节点 |
| 连线标签 | 放在对应线段中部附近，避免压箭头、折角和节点；必要时局部白底，不能遮住另一条边 |
| 边界与分组 | 边界标题在上方独立区域，连线跨边界不穿标题；线穿框边不代表与框建立关系 |
| 密度控制 | 整体缩放后仍可辨层次，原尺寸细节可读；交叉密集先重排/拆图，不无限加宽画布 |

箭头应终止于目标边缘或其规定的生命线/控制节点，不悬空，也不穿进节点文字。交叉线没有节点时不得画出暗示汇合的圆点；有真实汇合则采用对应记法的节点。跨图的同一元素保持名称和样式稳定。

## 默认配色

用户品牌/现有图稿优先；否则采用以下默认方案。颜色只辅助语义，必须搭配文字标签。

| 含义 | 建议填充 | 文字/边线 |
| --- | --- | --- |
| 应用/主要处理 | 浅蓝 `#DBEAFE` | 深蓝 `#1E3A5F` |
| 存储/数据 | 浅青 `#CCFBF1` | 深青 `#115E59` |
| 判断/待确认 | 浅黄 `#FEF3C7` | 深棕 `#92400E` |
| 成功/完成 | 浅绿 `#DCFCE7` | 深绿 `#166534` |
| 失败/风险 | 浅红 `#FEE2E2` | 深红 `#991B1B` |
| 外部/背景分组 | 浅灰 `#F1F5F9` | 深灰 `#334155` |

默认背景 `#FFFFFF`、正文 `#1F2937`、主要边线宽度约 2。`roughness`、填充纹理和字体按 [风格预设](style-presets.md) 选择；手绘通常用 1，简洁工程用 0。不靠噪点、阴影和图标数量营造层次。

线型必须服从选定记法，不能制定跨图种通用的“虚线=异步”。UML 时序图异步消息使用实线开放箭头，回复使用虚线；BPMN 的消息流另有规定。C4 关系用动作标签说明同步调用或事件发布，样式见图例。待确认项使用明确文字，不复用有既定含义的线型。状态颜色和环境颜色不要混用同一套含义。

## 导出方式

1. **编辑器导出**：实际打开本地源文件，检查画布，按需要导出 PNG 或 SVG 到成果目录。
2. **既有本地渲染器**：先检查其说明、依赖、可选参数以及是否加载远程字体/模块。用真实绝对输入输出路径执行，不假定它会自动放在目标目录。
3. **宿主集成导出**：按其返回文件操作；确认文件已实际保存且能读取，不将远端任务 ID 当成下载结果。

如果已安装的 `excalidraw-diagram` 提供 `render_excalidraw.py`，先按它的实际说明检查环境，再传入本次源文件和输出路径。不要盲用旧说明中的 `.claude/` 或 `.Codex/` 路径。首次依赖安装仅在授权范围内进行。

内部工程资料优先本地处理；开启公共协作房间、上传第三方服务或分享链接需要相应授权。浏览器页面可能加载远程依赖，不能因为文件是本地路径就声称全流程离线。

## 视觉检查

- 查看整体：阅读方向、层级、分区、图例和留白是否清楚。
- 查看原尺寸细节：中文/英文有没有缺字或溢出，长标签是否分行正确，箭头是否穿字、穿框或接错节点。
- 查看主路径及每个判断出口：图意是否与需求、源码一致，是否遗漏关键异常/失败终态。
- 检查编辑性：至少确认实际工具能打开/渲染该格式；有交互编辑器时抽查一个绑定节点及连线移动行为。
- 查看导出边界：没有截断标题/图例，没有因为固定视口宽度把大图裁掉。需要时拆图或调整导出范围。

PNG 和 SVG 都有时确认同一源版本；源文件一旦修订，受影响导出全部更新。不要用图像编辑修复源图中的结构错误。

## 环境受限时

没有渲染/浏览器能力：交付源文件和说明，标明“未导出，未视觉验证”，给出具体缺口。只能解析 JSON 时仅宣称结构检查，不能宣称 Excalidraw 导入兼容性或中文显示已验证。

已导出但无法查看：明确“已导出，待目视检查”。不能依据文件大小或命令退出码推断布局完美。没有实际产出的文件不出现在“已交付”列表中。
