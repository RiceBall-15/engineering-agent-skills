# 规范来源与约束性质

核对日期：2026-10-15。官方资料描述标准/方法；本技能另制定可执行的绘图与交付约定，二者不能混称。以下为选用版本，不声称永久是最新版本。

| 来源 | 本技能采用的内容 | 性质与限制 |
| --- | --- | --- |
| [C4 模型](https://c4model.com/diagrams) | 上下文/容器/组件的抽象范围，以及部署和动态视图 | 架构表达方法，不是强制图形语法；不要求每个项目画全部层级 |
| [C4 Notation](https://c4model.com/diagrams/notation) / [Review checklist](https://c4model.com/diagrams/checklist) | 图头、图例、元素身份/职责/技术、关系方向/标签/协议 | 官方建议，本技能将适用项设为默认验收要求；配色和坐标不是 C4 官方规定 |
| [OMG UML 2.5.1](https://www.omg.org/spec/UML/2.5.1) | 活动、时序、状态机常用符号及语义 | 正式规范；采用第 14–17 章相关子集，不宣称完整建模一致性 |
| [OMG BPMN 2.0.2](https://www.omg.org/spec/BPMN/2.0.2) | 用户需要 BPMN 时的事件、任务、网关、Pool 和连线 | 正式规范；不是每张技术流程图的默认要求，不等于生成可执行 BPMN |
| 本技能团队约定 | 默认选型、字段模板、间距/字号/颜色、文件目录、证据与审图记录 | 为工程交流制定的默认规则；可按明确项目规约调整，须保留语义和可读性 |
| [Excalidraw 属性与风格依据](style-presets.md#官方能力依据) | 粗糙度、填充、字体及回退机制 | 官方能力与技能预设分开；手绘、简洁工程和白板草图为本技能组合 |

未读取完整条文的其他标准不写成已落实要求；不使用“符合 ISO/IEC/IEEE 全部架构规范”等笼统声明。需要正式合规性或高级符号时应单独核对适用规范与范围。

同一记法内优先保持标准语义；品牌与手绘风格只调整呈现。若用户指定记法改变了语义，则标为自定义记法并说明差异，不能把错误记法包装成 UML/BPMN 子集。
